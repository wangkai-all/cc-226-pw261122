埋点识别与排除规则

重复埋点、后台自动请求、跨标签页行为的识别规则固定且可审计；被排除事件保留原始载荷。
重复埋点：相同 event_id，或相同业务指纹 （session + 类型 + 事件时间 + 查询/商品 + 标签页）即判重，含重新发送但换了 id 的信标。
后台自动请求：is_background=true 或来源为 api_health / suggest_prefetch，一律不进入查询路径。
跨标签页：路径按 session_id + tab_id 区分；点击/加购/转化按 session 作用域归因，所以在第二个标签页完成的转化仍归功于原搜索。
